# Broker prototype

`broker.py` contains the inherited lab token-broker source. `test_broker.py` includes HTTP integration tests that expect live Gitea; they are not part of the offline quickstart. A second copy is embedded in `cluster/broker.yaml`.

The implementation parses identity claims without cryptographic verification and includes development fallbacks. Do not use it to protect real credentials. See [known limitations](../docs/KNOWN-LIMITATIONS.md). Gitea passwords are generated by `cluster/gen_gitea_env.sh`; local environment files and signing keys are not distributed.
